# Credit_Card_Financial_Dashboard
Power BI Dashboard
📊 Credit Card Transactions & Customer Analytics Dashboard – Power BI Project

Developed an interactive Power BI dashboard using Credit Card Transaction and Customer datasets to analyze spending behavior, revenue trends, customer segmentation, and transaction performance.

🔹 Steps Performed:
• Data Cleaning & Transformation using Power Query
• Data Modeling & Relationship Building
• DAX Measures and KPI Creation
• Interactive Dashboard Design with Filters & Slicers
• Customer & Transaction Analysis

🔹 Key KPIs:
• Total Revenue
• Total Transactions
• Customer Count
• Average Spend per Customer
• Card Category Performance
• Monthly & Quarterly Trends

🔹 Insights Generated:
• Identified high-value customers and spending patterns
• Analyzed revenue contribution by card type and customer segment
• Tracked transaction trends and customer behavior over time

🔹 Business Impact / Usefulness:
• Helps businesses understand customer spending habits
• Supports data-driven decision making
• Useful for banking, finance, and customer analytics reporting

🛠 Tools Used: Power BI, Power Query, DAX, Data Modeling
